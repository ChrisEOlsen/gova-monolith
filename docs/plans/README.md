# This app's specs and plans

`gova-brainstorm` writes design docs to `../specs/`. `gova-writing-plans` writes
implementation plans here. `gova-brainstorm` reads both back as project history.

**Both directories are empty in a fresh app, and that is deliberate.** They used
to ship holding the plans and specs for how gova-monolith *itself* was built,
which every scaffolded project then inherited — so an app with one real plan
presented eleven, ten of them about somebody else's codebase.

Anything here should describe **this** app. A document about building the
template does not belong in a project and can be deleted.
